# Abartılı Kedi Miyav Çevirmeni

Bu proje, kedilerin çıkardığı her miyavı derin felsefi anlamlarla Türkçeye çevirir. Kediniz "Miyav" dediğinde aslında "İnsanlığın varoluşsal krizini düşünüyorum" diyordur. Bilim bunu henüz kabul etmedi ama biz ettik.

## Nasıl Çalışır?
Programı çalıştırın, bir miyav sesi yazın (örn: miyav, mırıltı, hışs), o da size abartılı çevirisini versin.

```bash
python kedi_cevirmen.py
```

Kediler yalan söylemez. Sadece biz anlamayız.
